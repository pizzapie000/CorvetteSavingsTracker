# Overview

I am developing this software to strengthen my understanding of object-oriented programming, user input, data storage, and problem-solving in C#. The goal is to create a practical console application while learning how to organize a program into classes, methods, and reusable pieces of logic.

The Corvette Savings Tracker is a console application that helps a user set a Corvette savings goal, record deposits, view deposit history, calculate savings progress, and estimate the time remaining until the goal is reached. The program saves the goal and deposit information to a text file so the user can continue tracking progress after closing and reopening the application.

I wrote this software to connect programming practice with a realistic personal finance problem. Building the tracker helped me practice C# syntax, including variables, expressions, conditionals, loops, methods, classes, lists, exception handling, and file input/output.

The software demonstration video will show the program running and provide a walkthrough of the source code, with a focus on what I learned about C# language syntax.

# Development Environment

I developed this project using Visual Studio Code and the .NET command-line tools. I used the .NET SDK to create, build, and run the console application.

The program was written in C# using the .NET 8 framework. It uses built-in .NET libraries, including System, System.Collections.Generic, System.Globalization, and System.IO. No external libraries are required.
